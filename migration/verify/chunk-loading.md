### R3 (inventory §2.2) — the `broadcastToPlayer` predicate does NOT filter global portals in the loader enumeration
- **Claim:** inventory §2.2 `foreachBaseChunkLoaders`: "(2) for each portal within `visiblePortalRangeChunks` (perf-tiered 8/3/1; global portals within 256 chunks) **that passes `portal.broadcastToPlayer(player)`**, the direct portal loader" (same reading implied for the indirect pass).
- **Evidence:** in `getNearbyPortals` the predicate is passed only to `McHelper.findEntitiesRough` (entity portals) (`ChunkVisibility.java:72-78`); global portals are appended on the distance test alone — `getDistanceToNearestPointInPortal(pos) < radiusChunksForGlobalPortals * 16` — with **no** `broadcastToPlayer` check (`ChunkVisibility.java:80-85`). A global portal failing `broadcastToPlayer` still produces direct/indirect loaders. (The doc's own `getNearbyPortals` bullet in §2.2 states this correctly; the `foreachBaseChunkLoaders` bullet contradicts it.)
- **Correction:** the predicate filters only non-global portals; global portals are distance-filtered only. A faithful port must NOT apply `broadcastToPlayer` to global portals here.
- **docPath:** `migration/inventory/chunk-loading.md`.

### R4 (api-map #18) — `TicketStorage.removeTicketIf` fires listeners per chunk (per tracker class), not "per removed ticket"
- **Claim:** api-map #18: "`removeTicketIf(TicketPredicate, @Nullable removedTickets)` (`:308-361`) **fires the tracker listeners per removed ticket**".
- **Evidence:** the inner loop only sets `removedLoading`/`removedSimulation` flags per removed ticket (`mc262-ref/net/minecraft/world/level/TicketStorage.java:328-334`); listeners fire **once per chunk per flag class**, after the loop, with the post-removal recomputed level (`:342-349`).
- **Correction:** per-chunk-per-class firing with the recomputed level. For IP's use (at most one `imm_ptl` ticket per (type,level) per chunk — dedup in `addTicket`, `:150-156`) the observable semantics are identical, so the doc's `removeTicketIf` recommendation stands.
- **docPath:** `migration/api-map/chunk-loading.md`.
