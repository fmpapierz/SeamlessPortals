Companion to `migration/inventory/portal-generation.md` §4 (the MC API touchpoint list). Every touchpoint there is classified below.

- **IP side** citations are into `C:/Users/warwa/ModDev/ImmersivePortalsMod/src/main/java/qouteall` (IP 1.21.3, Mojang mappings), abbreviated to package-relative names as in the inventory.
- **26.2 side** citations are `path/File.java:line` into `C:/Users/warwa/ModDev/mc262-ref` (decompiled vanilla 26.2, Mojang/official mappings). Every SAME/CHANGED verdict was verified by opening the cited 26.2 file.

## 5. Notes for the port spec (verified semantics, not new API)

1. **Height inclusivity flips (CHANGED 8-9) are the highest silent-corruption risk** in this slice: FastBlockAccess sizing, NetherPortalMatcher's Y-staging (`64..maxContentY`, full-height scans), `isAirCubeMediumPlace` build-limit rejection, and VerticalConnectingPortal's min/max-Y placement all do arithmetic with the old exclusive bounds through `McHelper` wrappers. Fix the wrappers (`getMaxYExclusive` → `getMaxY()+1`, `getMaxSectionYExclusive` → `getMaxSectionY()+1`), never the call sites.
2. **SavedData**: keep the on-disk `global_portal.dat` layout byte-compatible by writing the codec as a CompoundTag pass-through of the existing structure; version-upgrade path (v1→v2 no-op) folds into the codec's parse.
3. **Defaulted-registry lookup change (CHANGED 15)**: `BuiltInRegistries.ENTITY_TYPE` unknown-id behavior differs between `getValue` (pig, matching 1.21.3 `.get`) and `getOptional` (empty). Fidelity default: replicate 1.21.3 (`getValue`), but the pig fallback would then be `e.load`ed with portal NBT — same as upstream. Decide consciously.
4. All generation-pipeline mixin TARGETS survive structurally (S34-S36): `BaseFireBlock.onPlace`'s `findEmptyPortalShape` call, `isPortal`'s `Optional.isPresent`, `FlintAndSteelItem.useOn`, `ItemStack.useOn`, `ItemEntity.tick`. The only retargets are the ServerPlayer teleport pair (CHANGED 17-18) and the `thrower` shadow retype (CHANGED 19).
5. `EntitySpawnReason` (CHANGED 4) and the `@Block.UpdateFlags` value for BorderBarrierFiller (CHANGED 10) are the two spots where 26.2 forces a parameter IP never chose — both need explicit decisions recorded in the port spec, with vanilla-analog defaults proposed above.
