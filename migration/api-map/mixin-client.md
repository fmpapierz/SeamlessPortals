## 0. 26.2 architecture facts this whole slice hangs on (verified)

1. **Frame split into extract → render.** `Minecraft.runTick` drives `gameRenderer.update(deltaTracker)` → `pick(worldPartialTicks)` → `gameRenderer.extract(deltaTracker, advanceGameTime)` (`Minecraft.java:1290-1295`), and later `gameRenderer.render(...)`. `GameRenderer.update` `:372`, `extract` `:379`, `render(DeltaTracker,boolean)` `:396`, `renderLevel(DeltaTracker)` `:525` (`GameRenderer.java`).
2. **LevelRenderer split:** extraction lives in **`LevelExtractor`** (`net/minecraft/client/renderer/extract/LevelExtractor.java`, ctor `:89`, `extract` `:95`, `setLevel` `:393`, `allChanged` `:406`); drawing stays in `LevelRenderer.render(GraphicsResourceAllocator, DeltaTracker, boolean, CameraRenderState, Matrix4fc, GpuBufferSlice, Vector4f, boolean)` (`LevelRenderer.java:156`). They share `LevelRenderState` (`GameRenderState.java:10`).
3. **`ClientLevel` now holds a final `LevelExtractor`, not a `LevelRenderer`** (`ClientLevel.java:152,245,255`; block-dirty fan-out `:791-804`). There is **no `ClientLevel.levelRenderer` field**.
4. **Entities/BEs/particles render via submit nodes**, not `MultiBufferSource`: extract (`LevelExtractor.extractVisibleEntities` `:221`) → submit (`LevelRenderer.submitFeatures` `:279`, `submitEntities` `:653`) → execute (`FeatureRenderDispatcher.PreparedFrame.executeSolid/executeTranslucent/...` invoked at `LevelRenderer.java:419,434,436,440`). `MultiBufferSource`/`BufferSource` do not exist (no file; `RenderBuffers` has no bufferSource — `MIGRATION_API_MAP.md`).
5. **The camera owns view/projection**: `Camera.update(DeltaTracker)` `:93` → `alignWithEntity` `:249` → `prepareCullFrustum` `:195` → `setupPerspective` `:326`; view matrix built in `getViewRotationMatrix` from `rotation().conjugate()` via `Matrix4f.rotation(...)` (`Camera.java:384-392`, the `.rotation(...)` call at `:387`, dirty-flag cached). State copied to `CameraRenderState` in `extractRenderState` `:118` (pos `:127`, cullFrustum `:132`, projectionMatrix `:134`, viewRotationMatrix `:135`, `smartCull` `:122-125`, `isPanoramicMode` `:120`).
6. **Terrain visibility:** `LevelExtractor.applyFrustum` `:373-381` → `SectionOcclusionGraph.addSectionsInFrustum(frustum, levelRenderer.visibleSections(), nearbyVisibleSections())`; occlusion BFS updated in `LevelRenderer.render` via `sectionOcclusionGraph.update(...)` `:271`. `LevelRenderer.setupRender` does not exist.
7. **Terrain draw:** `LevelRenderer.prepareChunkRenders(Matrix4fc)` `:509` → `ChunkSectionsToRender.renderGroup(OPAQUE/TRANSLUCENT, sampler)` inside the `addMainPass` lambda (`:409`, `:438`). Raw-GL state (stencil, clip-distance) set before `renderGroup` persists — the GL encoder never touches it (`GlCommandEncoder.java:771-827`, per PHASE5 spec §0.7).
8. **A Vulkan backend exists** (`com/mojang/blaze3d/vulkan/VulkanBackend.java`). `GlStateManager`/`GlDebug` moved to `com.mojang.blaze3d.opengl` and are **GL-backend-only**; every raw-GL mixin in this slice (and the mod's shipped stencil chain) silently does nothing under Vulkan. Risk note, not a blocker for the GL default.
9. **Shaders:** `CoreShaders`, `ShaderInstance`, `CompiledShaderProgram`, `CompiledShader`, `Uniform` — none exist. Pipelines = `RenderPipeline` (registered `RenderPipelines.java:815`, built via `RenderPipeline.builder`), GLSL sources loaded + preprocessed by `ShaderManager` (`preprocessor.process(source)` `ShaderManager.java:89-93`; `getShaderSource` `:248`; `device.precompilePipeline(pipeline, cache::getShaderSource)` `:155`), uniforms = UBOs declared on `BindGroupLayout` (`BindGroupLayout.java:87`) and set per-pass via `RenderPass.setUniform` (vanilla example `SkyRenderer.java:329`).
10. **Fog:** `FogRenderer` reborn at `net/minecraft/client/renderer/fog/FogRenderer.java` — instance-based: `setupFog(Camera,int,DeltaTracker,float,ClientLevel)` `:167` returns `FogData` (`fog/FogData.java:8-15`: `environmentalStart/End`, `renderDistanceStart/End`, `skyEnd`, `cloudEnd`, `color`); `updateBuffer(FogData)` `:188`; `getBuffer(FogMode)` `:76`; applied via `RenderSystem.setShaderFog(GpuBufferSlice)` (`RenderSystem.java:112`).
