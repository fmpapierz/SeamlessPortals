## 6. Top risks (hardest gaps in this slice)

1. **Client world/renderer swap** — `Minecraft.levelRenderer` is final and split into `LevelRenderer` + `LevelExtractor` (Minecraft.java:280-281); IP's per-dimension renderer reassignment has no direct form. Must be reconciled with the mod's existing promote/demote extractor design. (GONE row 6.)
2. **`Entity.checkInsideBlocks` rework** — bb-based redirect+cancel must be redesigned against the movement-path walker (`makeBoundingBox(to)` at Entity.java:1302). (CHANGED row 6.)
3. **`lerpTo` removal** — every interpolation-kill (updateEntityPos RPC, adjustVehicle) re-targets `InterpolationHandler` + `snapTo` + `getPositionCodec().setBase`, gated by `isLocalInstanceAuthoritative`. (GONE row 1 + CHANGED row 22.)
4. **Vanilla-copied collision bodies** — `collide`/`collideBoundingBox`/`collideWithShapes` all changed internally (`axisStepOrder`, `collectCollidersIgnoringWorldBorder`, step-up epsilon); the gravity-generalized copies must be re-derived from 26.2, not patched. (CHANGED rows 8-10.)
5. **Position-sync overwrite** — `teleport(PositionMoveRotation, Set<Relative>)` + record packet + `Relative` enum + accept-handler's new `hasChangedDimension()` call; the dimension-tag protocol must be re-stamped onto the new shapes. (CHANGED rows 11-12; SAME 3.3.)
6. **Ender-pearl mixin redesign** — vanilla now teleports the owner cross-dimension natively via `TeleportTransition` (ThrownEnderpearl.java:103-147); IP must intercept that flow, not add a missing case. (CHANGED row 17.)
7. **Anticheat re-implementation** — `isEntityCollidingWithAnythingNew` + `getPreMoveCollisions` (ServerGamePacketListenerImpl.java:1243; CollisionGetter.java:90), now also covering vehicles. (CHANGED row 13.)
8. **Camera re-setup** — `Camera.setup(...)` → pull-model `Camera.update(DeltaTracker)` with `setLevel`/`setEntity` state (Camera.java:93, :491, :411); TransformationManager's immediate re-setup and MixinGameRenderer's hook ordering vs `GameRenderer.update` (:372) need re-derivation. (GONE row 2.)
